## Root Cause Analysis

### Why Did This Happen?

1. **Inconsistent naming**: Task uses `title`, but Sprint and Track use `name`
2. **No static type checking**: Python's dynamic nature allowed incorrect attribute access
3. **Insufficient testing**: Runtime tests didn't catch the attribute error
4. **Recent development**: CLI commands may not have been fully tested with actual Task objects

### How Was It Missed?

1. **Code may have been written before Task model finalized** on `title` field name
2. **Confusion between models**: Developer assumed Task used `name` like Sprint/Track
3. **Test coverage gaps**: Tests may use mocks or fixtures instead of real Task objects
4. **No type hints enforced**: Missing mypy or similar static analysis
