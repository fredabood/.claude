## Analysis

### Auto-Generation System

The CLI reference is generated by:
```bash
vibey docs generate-cli -o docs/reference/CLI_REFERENCE.md
```

This command:
1. Introspects the Click command tree
2. Extracts all commands, options, and arguments
3. Generates markdown documentation
4. Cannot drift from implementation by design

### Drift Detection

```bash
vibey docs check-drift
```

This command:
- Compares current documentation with regenerated version
- Fails CI if drift detected
- Ensures documentation stays in sync
